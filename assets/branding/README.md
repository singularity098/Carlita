# Carlita branding

The Carlita mark is **Patch Bay Bloom**: six input jacks arranged in a ring so
they form a flower, each with a ring that blends from pink to purple, around a
gradient hub. It is made for dark backgrounds; `carlita-logo-light.svg` is the version for
light ones.

| File | Use |
| --- | --- |
| `carlita-logo.svg` | Mark and wordmark side by side (README, splash, idle screen) |
| `carlita-logo-light.svg` | The same with a dark wordmark, for light backgrounds |
| `carlita-icon.svg` | Mark alone on a transparent background |
| `carlita-app-icon.svg` | Mark on a dark rounded tile (desktop and AppImage icon) |
| `carlita-wordmark.svg` | Wordmark alone |
| `png/carlita-app-icon-<size>.png` | App icon at 16–1024 px (window icon uses 256) |
| `png/carlita-icon-<size>.png` | Transparent mark at 32–512 px |
| `png/carlita-logo.png` | Logo at 240 px tall |

The SVGs are the source; the PNGs are rendered from them. The wordmark is set
in [Sora](https://fonts.google.com/specimen/Sora) SemiBold (SIL Open Font
License) with letter-spacing of −0.03 em, converted to outlines so no font is
needed to display it.

## Colors

| Name | Hex | Where |
| --- | --- | --- |
| Pink | `#ff5fae` | Gradient start (top of the flower, "i" of the wordmark) |
| Orchid | `#c25cf0` | Gradient midpoint |
| Purple | `#7d5cff` | Gradient end (bottom of the flower, final "a") |
| Wordmark | `#eef0f5` | "carl" (`#1a1d25` on light backgrounds) |
| Jack body | `#2b303b` | Outer jack disc |
| Jack nut | `#3a4152` | Inner ring |
| Socket | `#0b0c10` | Jack holes |
| Tile | `#1f2330` → `#12141b` | App icon background |
